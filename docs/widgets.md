# Writing a widget

The widget standard lives with the widgets:
[src/Hearth.App/Widgets/README.md](../src/Hearth.App/Widgets/README.md).

Each widget is one folder under `src/Hearth.App/Widgets/`, with its own
`README.md`. Shared parts are in `Widgets/Framework/`
([README](../src/Hearth.App/Widgets/Framework/README.md)). Widgets are found
automatically, so adding or removing one means adding or removing its folder.
